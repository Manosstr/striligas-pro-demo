# Striligas Pro – demo

Στατικό δοκιμαστικό demo της πύλης επαγγελματιών Striligas Pro: https://manosstr.github.io/striligas-pro-demo/

- Δοκιμαστική λειτουργία: καλάθι, παραγγελίες και προσφορές αποθηκεύονται μόνο στον browser σας και δεν αποστέλλονται πουθενά.
- Οι μοναδικές πραγματικές τιμές είναι του καμβά με τελάρο (χωρίς ΦΠΑ 24%). Τα υπόλοιπα προϊόντα είναι «κατόπιν προσφοράς».
- Η σύνδεση είναι απλό φράγμα στον browser, όχι ασφάλεια: οι τιμές υπάρχουν μέσα στον κώδικα της σελίδας.

Το αποθετήριο περιέχει μόνο το έτοιμο build. Ο πηγαίος κώδικας δεν είναι δημόσιος.
